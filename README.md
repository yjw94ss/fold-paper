# FOLD PAPER · 一纸千折

为 OPPO Find N5 折叠屏做的单文件益智游戏：纸上打了若干孔，把纸折起来，让所有孔重叠成一个孔。

- 单文件 `index.html`，零外部请求，可离线
- 拖动纸边箭头折叠，折痕落在格线上；折过来的部分不能大于留下的部分
- 18 关，每关的最优折数由求解器精确给出（一维分解 + BFS），三星门槛 = 最优折数
- 进度存 localStorage

## 关卡是怎么验出来的

折叠规则可以按轴分解：x 坐标只受左右折影响，y 只受上下折影响，且合法性约束 `2k ≤ 边长` 各自独立。
于是 par = par_x + par_y 精确成立，可以用两条一维纸条的 BFS 求出最优解。

`tools/gen5.py` 穷举了长度 2..9 的所有孔位组合（2^n 个掩码），只保留「每一折都至少合上一对孔」的
最优解，再拼装成二维关卡。`tools/fixture.json` 是标准答案（每关的折法与折完后的落孔坐标），
`test.cjs` 用 Playwright 驱动真实浏览器逐关复核。
